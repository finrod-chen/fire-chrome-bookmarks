# Chrome Web Store listing

Category: Productivity · Language: English (default) + 中文（繁體）

## Single purpose
Add tags to Chrome bookmarks and search them by keyword from the address bar.

## Permission justifications
- bookmarks: Tags are stored in bookmark titles; the extension reads bookmarks to search them and creates/updates/deletes the bookmark the user edits.
- activeTab: Reads the current tab's title and URL only when the user clicks the icon or presses the shortcut, to bookmark that page.

Remote code: No. Data usage: collects no user data.
Privacy policy URL: https://github.com/finrod-chen/fire-chrome-bookmarks/blob/main/PRIVACY.md

## Description (EN)
Firefox-style bookmark tags for Chrome.

• Press Alt+Shift+B, type a few tags, press Enter.
• In the address bar, type "bm", a space, and keywords to find any bookmark. Every keyword must match. Words starting with # match tags only.
• Full-page search with a tag cloud and keyboard navigation.
• Tags live in the bookmark title, so they sync with Chrome and survive export. No extra storage.
• No data collection, no network requests, no tracking.

## 說明（繁中）
把 Firefox 的書籤標籤搬到 Chrome。

• 按 Alt+Shift+B，輸入幾個標籤，Enter 儲存。
• 網址列輸入「bm」加空白再打關鍵字，就能找回書籤；所有關鍵字都要命中，# 開頭只比對標籤。
• 整頁搜尋，含標籤雲與鍵盤操作。
• 標籤存在書籤標題裡，跟著 Chrome 同步，匯出也不會遺失，不佔額外空間。
• 不收集資料、沒有網路請求、沒有追蹤。
