# Privacy Policy / 隱私權政策

_Last updated: 2026-11-11_

**Bookmark Tags does not collect, store, transmit, or sell any personal data.**

- All processing happens locally in your browser.
- Tags are saved in your Chrome bookmark titles through the `chrome.bookmarks` API. If you use Chrome Sync, Google syncs your bookmarks under Google's own privacy policy; this extension adds nothing to that.
- The extension makes no network requests and contains no analytics, ads, or third-party code.
- `activeTab` is used only to read the current tab's title and URL when you open the extension, so the page can be bookmarked.

**Bookmark Tags 不收集、不儲存、不傳送、也不販售任何個人資料。**

- 所有處理都在你的瀏覽器本機進行。
- 標籤透過 `chrome.bookmarks` API 存在你的 Chrome 書籤標題裡。若你開啟 Chrome 同步，書籤由 Google 依其隱私權政策同步，本擴充功能不另外處理。
- 本擴充功能沒有任何網路請求，不含分析、廣告或第三方程式碼。
- `activeTab` 只在你開啟擴充功能時讀取目前分頁的標題與網址，用來加入書籤。
